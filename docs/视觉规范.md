# 简历大冒险 · 视觉规范

> 方向：8-bit 横版闯关。像一款真的红白机游戏，而不是「套了游戏皮的网页」。
> 只有**简历纸面**保持专业排版——那是给 HR 看的。

## 1. 原则

1. **画在场景上，不放进卡片里。** HUD 直接写在天空上（白字 + 硬阴影），不加底框、不用毛玻璃、不用圆角药丸。
2. **对话框就是游戏对话框。** 深蓝底 + 白色双线边框 + 直角，像 RPG 的文字框。
3. **按钮是实心像素砖。** 3px 黑描边、内高光、右下硬投影，按下时下沉 2px。
4. **所有图形都是像素画。** 小人、方块、水管、云、山都用画布按像素绘制，`image-rendering: pixelated`，整数倍放大。
5. **原创角色。** 主角「小简」是原创像素小人（青色毛线帽、橙色围巾、手拿简历），不使用任何现有游戏角色。

## 2. 色板

| Token | 白天关卡 | 地下关卡（深色模式） | 用途 |
|---|---|---|---|
| `--sky` | `#5C94FC` | `#0C0A24` | 页面底色 |
| `--ink` | `#14101E` | `#14101E` | 描边、硬阴影 |
| `--box` | `#1D1B3A` | `#101032` | 对话框底 |
| `--box-fg` | `#FCFCFC` | `#FCFCFC` | 对话框文字 |
| `--gold` | `#F8B800` | `#F8B800` | 问号块、主按钮、命中金币 |
| `--brick` | `#C84C0C` | `#2C64C8` | 砖块、地面（地下变蓝砖） |
| `--pipe` | `#00A800` | `#00A800` | 水管、藤蔓、次按钮 |
| `--red` | `#E4002B` | `#FF4060` | 删除、缺失 |

简历纸面固定：白纸 `#FFFFFF`、正文 `#1F2328`、次要 `#5B6470`，强调色可选 砖红 / 水管绿 / 夜空蓝。

## 3. 字体

| 角色 | 字体 | 字号（只用整数倍） |
|---|---|---|
| 中文像素标题 / 按钮 / 路牌 | Fusion Pixel 12px（OFL，已内嵌） | 12 / 18 / 24 / 36 / 72 |
| 英文 HUD / 数字 | Press Start 2P | 8 / 10 / 12 / 16 |
| 正文 / 表单 / 简历 | Noto Sans SC | 13–16 |

## 4. 组件

- **HUD**：PLAYER / COINS / ITEMS / WORLD / MATCH 五栏，左对齐排开，数字用 Press Start 2P。
- **世界地图条**：三个关卡节点由虚线小路连接，当前关卡头顶站着小人。
- **经历藤蔓**：方块 → 路牌 → 藤蔓（4px 绿色竖线）→ 叶子（横枝 + 金币 + 文字）→ 地面日期。
- **金币标签**：圆形像素金币 + 文字，命中为亮金，缺失为灰色空块。
- **过场**：切关卡时黑屏显示 `WORLD 1-2`，0.7 秒；生成简历后中央大字 `COURSE CLEAR!`。

## 5. 动效与声音

- 顶方块：方块上弹 8px + 金币飞出（0.35s）。
- 小人：两帧走路，跳跃抛物线 0.45s。
- 音效：WebAudio 方波合成（金币、跳跃、顶块、钻管、通关），HUD 右侧 ♪ 可关闭。
- `prefers-reduced-motion`：关闭过场与位移动画，直接切换。

## 6. 响应式

- ≥ 960px：角色卡与道具栏并排；简历与结算面板并排。
- < 960px：全部单列；关卡卷轴保持横向滚动（容器内滚动，页面本身不横滚）。
