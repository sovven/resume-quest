## 1. 背景与问题

求职时，一份简历投所有岗位，命中率很低。HR 和 ATS 筛简历看的是「和这个 JD 对不对得上」。但每投一个岗位就手改一次简历，有三个痛点：

1. **经历散落**：过去的项目、实习、奖项散在各个旧简历、作品集、聊天记录里，每次都要重新翻。
2. **不会对齐 JD**：不知道 JD 里哪些词是重点，也看不出自己哪里缺。
3. **改简历很枯燥**：重复劳动，没有反馈，越改越烦。

## 2. 产品定位

> 把「整理经历 → 读懂 JD → 生成专属简历」做成一个闯关游戏。

- **一次录入，反复使用**：经历像时间线地图一样摊开，录一次，之后每个岗位都从这里取材。
- **JD 一贴就懂**：自动提取关键词，标出你「有的」和「缺的」。
- **一键生成专属简历**：只用你真实的经历，按岗位挑选、排序、高亮。可选 Claude 精修措辞。
- **有趣**：横版闯关的视觉和音效，填资料像吃金币，生成简历像通关。

## 3. 目标用户

| 用户 | 特征 | 核心诉求 |
|---|---|---|
| 应届生 / 在校生（主） | 经历多为项目、实习、比赛；海投、校招 | 快速出多版简历；知道自己缺什么 |
| 1–5 年转岗 / 跳槽者 | 经历多，需要按岗位取舍 | 删掉无关经历，突出相关成果 |
| 设计 / 新媒体 / 创意岗 | 在意简历观感，排斥呆板工具 | 好用又好看，愿意分享到小红书 |

## 4. 目标与衡量

| 目标 | 指标 | MVP 目标值 |
|---|---|---|
| 降低单次定制成本 | 从贴 JD 到导出简历的时间 | < 3 分钟 |
| 提高贴合度 | 生成简历覆盖的 JD 关键词比例（匹配度） | 平均提升 20 个百分点以上（对比原简历） |
| 留存 | 7 日内再次打开并生成第 2 份简历的比例 | > 40% |
| 真实性 | 生成内容出现档案中不存在的经历/数据 | 0（硬约束） |

## 5. 核心流程（三个关卡）

```
WORLD 1-1 经历地图  ──▶  WORLD 1-2 JD 管道  ──▶  WORLD 1-3 专属简历
 录入/编辑经历            粘贴 JD，提取关键词         生成、微调、导出
 （时间线 + 思维导图）     （命中 / 缺失 / 对照表）     （匹配度 + 补强建议）
```

### 5.1 WORLD 1-1 经历地图（时间线 + 思维导图）

- 横向卷轴关卡，**时间从左到右**。每段经历是一根从地面长出的「藤蔓」：
  - 顶端是**方块**（类型图标：教育=水管、工作=砖块、实习=蘑菇、项目=问号块、奖项=星星、其他=金币）。
  - 方块下是**路牌**：职位/专业、机构、类型。
  - 藤蔓上的**叶子**是成就要点（一条一个），**金币**是技能标签。——这就是思维导图的分支结构。
  - 地面上写着起止时间，相当于时间轴刻度。
- 小人可以用 ← → 走、空格跳；走到某段经历下面跳一下 = 顶方块 = 打开编辑框。点方块也行。
- 关卡末尾有「+」方块（新增经历）和终点旗杆（进入下一关）。
- 下方两个面板：
  - **角色卡**：姓名、求职意向、电话、邮箱、城市、作品集链接、个人简介。
  - **道具栏**：技能，每个技能 1–3 星熟练度。
- **导入旧简历**（AI）：粘贴旧简历文本，Claude 拆成结构化经历，追加到地图上。
- **存档**：自动保存；可导出/读取 `.json` 存档文件。

### 5.2 WORLD 1-2 JD 管道

- 粘贴 JD 文本，填写（或自动识别）公司、岗位名。
- 点「丢进管道」：JD 纸片滑进水管，关键词以金币形式弹出：
  - **金币（亮）** = JD 要求 & 你的档案里有。
  - **空块（灰）** = JD 要求但你的档案里没找到。
  - 「优先 / 加分」类关键词单独标注，权重减半。
- **需求对照表**：JD 每条任职要求 → 命中哪段经历 / 部分命中 / 缺失。

### 5.3 WORLD 1-3 专属简历

- **生成简历（本地）**：即时，离线可用。规则见 §7。
- **Claude 精修（AI）**：在 claude.ai 中打开时可用，改写措辞、STAR 化、自然融入关键词。
- 纸面简历可直接点击修改（所见即所得）。
- 模板：经典黑白 / 主题色（可选 3 种强调色）。
- 导出：复制纯文本、下载 Markdown、下载 HTML（可在浏览器里打印成 PDF）；本地版直接「打印 / 存 PDF」。
- 结算面板（COURSE CLEAR）：匹配度星级、命中关键词、缺失关键词、补强建议。

## 7. 规则说明

### 7.1 关键词提取（本地）

1. **领域词典**：设计、产品、运营、新媒体、开发、数据、3D/动画、语言、学历等常用词，含同义词（如 PS = Photoshop，AE = After Effects）。
2. **英文词**：JD 中所有英文/工具名（Figma、SQL、Python…），过滤停用词。
3. **中文句式**：「熟悉 / 精通 / 掌握 / 熟练使用 / 具备 / 有 … 经验/能力」中间的短语，按「、和及或/」拆分。
4. **档案反查**：你的技能和标签如果出现在 JD 里，也算关键词。
5. **权重**：任职要求段 ×1.2；含「优先 / 加分」的行 ×0.5；同一词出现多次 +0.2/次（上限 +0.6）。

### 7.2 匹配度

`匹配度 = Σ 命中关键词权重 ÷ Σ 全部关键词权重 × 100`，四舍五入。星级：≥80 三星，≥60 两星，≥40 一星。

### 7.3 本地生成简历

- **模块顺序**：累计工作/实习 ≥ 24 个月 → 工作经历在前；否则教育背景在前（应届惯例）。
- **经历取舍**：教育全保留；其他模块按相关度打分，保留得分 > 0 的条目（每模块最多 4 条），若都为 0 则保留最近 1 条。模块内按时间倒序。
- **要点**：按相关度重排，每段最多 5 条，命中的关键词加粗。
- **个人优势**：用你的简介 + 一句「与本岗位契合：A、B、C」。
- **技能**：只列你自己的技能，命中的排前面。

### 7.4 Claude 精修（AI）

- 硬约束写进提示词：**只能使用档案里真实存在的经历、时间、数据；不得编造**；可以改写措辞、合并拆分要点、调整顺序、删除无关条目。
- 返回结构化 JSON（模块、条目、要点、技能、命中词、缺失词、匹配度、建议），前端渲染。
- 失败处理：未授权 → 隐藏 AI 按钮；限流 → 提示稍后再试；其他 → 保留本地版本。

## 8. 数据模型

```json
{
  "profile": {
    "basics": { "name": "", "title": "", "phone": "", "email": "", "city": "", "link": "", "summary": "" },
    "skills": [{ "name": "Figma", "level": 3 }],
    "items": [{
      "id": "x1", "type": "edu|work|intern|project|award|other",
      "org": "机构/学校", "role": "职位/专业", "start": "2023-09", "end": "2024-06 或空(至今)",
      "bullets": ["成就要点"], "tags": ["技能标签"], "sample": false
    }]
  },
  "jd": { "text": "", "company": "", "position": "" },
  "prefs": { "sound": true, "tpl": "classic", "accent": "brick" },
  "updatedAt": 0
}
```

存储：浏览器 localStorage（键 `rq.v1`）；在 claude.ai 中额外写入私有文档 `data/users/<我的id>/resume-quest`，别人（包括分享对象）看不到。

## 9. 非目标（本版不做）

- 不做账号体系、不做招聘网站对接/自动投递。
- 不抓取招聘网站页面（只接受粘贴文本）。
- 不替用户编造经历或数据。

## 10. 风险与对策

| 风险 | 对策 |
|---|---|
| AI 编造经历 | 提示词硬约束 + 只传档案数据 + 生成后可逐字修改 |
| 本地关键词提取不准 | 词典 + 句式 + 档案反查三路合并；用户可在简历上直接改 |
| 游戏化喧宾夺主 | 简历纸面保持专业黑白排版；音效可关；动效遵守「减少动态效果」设置 |
| 本地数据丢失 | 自动保存 + 云端存档 + 一键导出 `.json` |
| 隐私 | 数据只在本机或用户私有云文档；不上传第三方 |

## 11. 验收标准

- [ ] 打开即看到示例档案和示例 JD（带「示例」标记），3 步内能生成一份简历。
- [ ] 新增一段经历后，地图按时间插入正确位置，刷新后仍在。
- [ ] 粘贴 JD 后，关键词分为命中/缺失，匹配度数字与规则一致。
- [ ] 生成简历只包含档案中的信息；可直接编辑；导出的 md/html/txt 与屏幕一致。
- [ ] 手机宽度（≈400px）可用，页面不横向滚动（关卡卷轴除外）。
- [ ] 系统深色模式下切换为「地下关卡」配色，文字可读。
